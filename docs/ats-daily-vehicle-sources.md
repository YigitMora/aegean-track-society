## Sprint 4P Rating Notes

- Courier commercial rows are treated as useful road/commercial vehicles, not track cars. Transit Courier handling and Track Readiness stay below or equal to Tourneo Courier where evidence is similar.
- Manual and automatic rows are split only when transmission, output, acceleration, or hybrid/electric architecture changes.
- Daily EV rows receive acceleration credit in Power but retain mass, thermal, and Track Readiness limits.
- No Sprint 4P daily row is intended to exceed 75 Overall.
